# B+OPEN

Website được khôi phục từ b+open-3.zip, dùng React, TypeScript, Vite và Tailwind CSS.

## Chạy website

Yêu cầu Node.js 22 trở lên. Trong thư mục này:

```sh
npm ci
npm run dev
```

Mở địa chỉ Local do Vite hiển thị.

## Đóng gói

```sh
npm run build
npm run preview
```

Bản tĩnh nằm trong dist/. Các trang dùng hash routing.

## Phạm vi

Giữ nguyên giao diện, nội dung và tính năng của bản ZIP. Không cần Gemini API key.
Ảnh, font, video, PDF và showroom nhúng từ bên ngoài cần Internet.
Các biểu mẫu mô phỏng gửi thông tin, chưa kết nối dịch vụ email hay máy chủ.
Website B+ON ở thư mục cha được giữ nguyên.
